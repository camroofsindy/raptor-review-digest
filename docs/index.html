What's driving them

The 10% monthly review velocity (34 new reviews on a 325-base) is not happening by accident — this is a deliberate, systematized ask strategy, not organic luck.

Deploy LocalBusiness / RoofingContractor JSON-LD schema with AggregateRating on Raptor's homepage and all city-level service pages this week. This is a two-hour developer task, not a content project.
